What I built

  • A storefront filtering client that queries an external search service and builds its filters from product metafields: allergens, certifications and chocolate type.
  • Allergen normalisation: the same allergen appears under different spellings across the store's three languages and supplier data, so each one is reduced to a canonical name with an alias list. A shopper filtering on the German, English or French term lands on the same results.
  • The client resolves its own API endpoint from the shop domain, so production and staging each hit their own search index with no config change.
  • Customer login page, product page adjustments and DE/EN/FR translation work across the storefront.
