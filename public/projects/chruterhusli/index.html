What I built

  • Wishlist, end to end: instead of browser storage, the client talks to a Shopify app proxy, so the list is held server side. Add, fetch, remove one and clear all are separate endpoints, and the button reconciles its state against the server on load so a saved item still reads as saved after a reload.
  • Every user-facing string comes from the theme's locale files with English fallbacks, so the feature stays translatable.
  • Contact page: the form and its confirmation flow.
  • Collection page: promotional image blocks with tablet-specific layout logic, the filter and results-count header, and product card alignment.
  • Blog list and article layouts, product page breadcrumbs and spacing, and DE/EN translation work.
