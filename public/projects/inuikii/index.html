Inuikii

What I built

  • Search: Shopify's native search replaced with a Meilisearch storefront layer across search and collection pages, with colour grouping, market-aware pricing and instant results.
  • A back-in-stock and notify-me flow that replaced a paid third-party app, a size guide with per-product size scales, storewide sale pricing and a returns and refund-request flow driven by order tags and fulfilment status.
  • Virtual Showroom: a private B2B catalogue with prices, cart and checkout removed, and article numbers, size ranges and buyer-focused navigation added.
  • Influencer store: a private storefront with a Klaviyo integration that tags subscribers by store source.
  • Checkout app: a TypeScript Shopify app with an unsubscribe API and a Checkout UI extension showing editorial story cards in checkout and on the thank-you page.
  • Full DE/EN localisation.
