Built at aiconomy AG · internal app

PrestaShop to Shopify migration app

An admin app that migrates customers and historical orders from PrestaShop into Shopify through the Admin GraphQL API. Built once and run per market, first Switzerland and then the UAE.

How it works
  • The hard requirement was silence. Importing tens of thousands of historical customers and backdated orders into a live store would, by default, email every customer an account invitation and an order receipt.
  • The guarantee is enforced by the build: order creation is reachable through a single function that hardcodes the receipt options to false and bypasses inventory, customers are created without a password or invited state, and a guard test fails the build if the invite mutations are ever referenced.
  • A three-file upload stepper for the PrestaShop exports, with a dry run by default: parsed counts, per-file previews, unmatched customers, missing SKUs and blocked rows, all before anything is written.
  • Import is a separate action behind a confirmation that restates the no-email guarantee and the target shop domain. It runs customers then orders oldest first, reports live progress and can be cancelled.
  • Idempotent and resumable, so a failed run can be re-run safely, with a downloadable CSV report of every source row.
  • React Router
  • TypeScript
  • Prisma
  • Admin GraphQL API
